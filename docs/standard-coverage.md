# GB/T 42133—2022 标准对照

依据用户提供的 PDF（2022-12-30 发布、2023-07-01 实施）。以下记录的是本阅读器 0.3.0 的 OFD 实现边界，不是认证结果。GB/T 42133 是档案应用指南，完整 OFD 文件结构仍以其引用的 GB/T 33190 为依据。

## 渐变显示范围

轴向渐变支持多段颜色、缺省 Segment 位置插值、Direct/Repeat/Reflect、重复区间 MapUnit，以及 Extend 0–3。渐变随对象坐标变换和页面旋转，支持填充、描边、文字轮廓及已有路径裁剪；颜色空间、颜色表与透明度沿用绘制参数。颜色通道可使用十进制或以 # 开头的十六进制值。

径向渐变支持起始半径为 0、焦点位于结束圆内的圆形渐变，以及结束圆外的 Extend 控制。非零起始半径、椭圆参数、焦点在结束圆上或圆外、径向 MapUnit 会在检查报告中提示并回退到首段颜色。Gouraud/LaGouraud 网格渐变和 Pattern 图案尚未实现。

每个渐变支持 2–64 个颜色段。非法坐标、颜色值、颜色段位置或渐变参数会报错；超过颜色段上限也会拒绝打开。转换和打印使用渲染后的页面外观，渐变不会作为可编辑的矢量渐变保存在输出中。

## 原文件保护

本程序只读解析源文件，不执行指南中的去技术化、去除附件、去除加密、移动页面或签名处理。这些是归档生成/处理软件职责，不能在阅读时擅自改变原件。

## 检查提示的解释

- error：缺失资源等会影响内容完整性的问题。
- warning：归档建议、未支持的特性或需要人工复核的事项。
- info：OFD-A 只读等信息。

当前报告主要记录结构和已解析节点的静态检查。渲染时发现的损坏图片、缺字等另外显示在当前页渲染提示中；界面导出的静态报告不替代逐页视觉复核。

## PDF 与打印

PDF 是独立文件格式；PDF 阅读提示不用于 GB/T 42133 合规判断。PDF 文字搜索依赖文字层和正确编码，复杂字体、未知 CMap 和扫描件仍有限制。

默认中文字体已内置 Noto Sans SC 常规字重。内置字体改善界面和替代字体可用性，不会把缺少嵌入字体的 OFD 自动变成合规档案，也不改变源文件。

OFD/PDF 均支持连续阅读和打印。打印采用栅格化页面，Windows 使用系统打印窗口和 GDI 打印设备，Linux 使用 CUPS。OFD 的 Print Printable=false 会禁止打印。打印预检会拒绝带渲染提示的页面；打印不代表数字签名认证，也不保留签名结构。

## 0.3.0 注释、编辑和签名边界

新增注释和编辑采用工作副本及独立编辑项目，不改写原件。OFD-A 的只读约束仍在核心层和界面层执行。保存文档副本使用页面外观重建；不能把转换副本理解为原签名的连续保存，也不能把新增文本理解为原文段落编辑。

PDF 内嵌签名为 RSA/SHA-256 的 CMS，adbe.pkcs7.detached。OFD 的 .p7s 仅是包文件整体的通用 CMS 完整性签名，未实现 GB/T 38540 国密电子签章；不改变原有 OFD 内部签章验证边界。

验签核对原始字节/ByteRange、CMS 签名及摘要，展示证书指纹和当前有效期，不验证 CA 信任链、吊销和可信时间戳。可见印章图片与数字签名结果独立。
