# Application icons

The user supplied original RGBA PNGs at 32, 48, 64, 96, 128, 256 and 512 pixels. They are copied without changing artwork or scaling.

app.ico stores the supplied PNG bytes for sizes 32 through 256 as six icon frames. The 512-pixel PNG is retained for Linux icon installation. Windows resource compilation embeds app.ico, the window uses icon-256.png, and the header uses icon-48.png.

These images are user-provided application artwork. No third-party license is inferred.
